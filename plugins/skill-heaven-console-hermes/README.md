# Hermes Skill Heaven Full console

Separate Python plugin plus the shared generated Node report. Full registration
is **not blocked**: the profile installer prepares an independent Git root that
Hermes clones via its supported file-URL plugin installation.

`/heaven [section] [--session-root <exact root>]` prints the brief shared report
(<=8 lines). `/heaven inspect <section>` adds diagnostics. `/lens <need>` prints a
preview handoff only; `/lens inspect <need>` reveals the deliberate submission
recipe. It never dispatches Core tools, starts a summon server, submits a prompt
or reads unrelated transcripts. Normal host approval applies to human submission.
No persistent statusline/pane or agent telemetry is claimed. Without an exact
current-conversation session binding, counts are unknown and reads unavailable.

Saved native **0.20.0 (2026.8.3)** profile management passed Core→Full→Core→remove.
Compilation and shared fixture conformance are not a full live runtime receipt.
Remaining command/report, permission/isolation/cache-refresh cells stay explicit.
Disable then remove selected package; Core survives console-only removal.

See [canonical controls and limits](../../packages/console/README.md).
Full is a Skill Heaven terminal profile, not the Gaia Ecosystem Desktop Mod.
