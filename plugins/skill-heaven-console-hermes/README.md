# Hermes Full console (preview; registration blocked)

Native plugin identity `skill-heaven-console`; Python register_command plus bundled
canonical Node painter. `/heaven [section] [--session-root <exact Core root>]` is
stateless. `/lens <need>` dispatches only an unambiguous exact Core namespace with
preview:true. Its one result is not mistaken for complete session history.
No session buffer, database scan, hooks, daemon or config writes.

Hermes 0.20.0 installs Git sources: file:// registration requires an independent
Git root, not this plain staged directory. Full remains blocked until staging is
established. `hermes plugins disable skill-heaven-console` disables only Console.
Saved API/source evidence and synthetic checks are not a runtime Full receipt.
See [adapter contract and remaining cells](../../packages/console/README.md).
