# Pi Skill Heaven Full console

Separate, removable Full piece; Core does not register it. Requires **Pi 1.1+**
and **pi-tui 0.84.1+**, not the old 1.0.4 API-only pin.

One compact owned `setStatus` contribution; `SKILL_HEAVEN_STATUS=off` removes it.
`/heaven` deliberately opens the official SDK overlay. 1–6/Tab/arrows select
surfaces; i toggles inspection; inspected details page/scroll; Escape/q/Ctrl+C
close and restore the editor. Physical rows stay within terminal rows minus eight.
Ordinary tool results never open a pane or register a widget.

`/lens <need>` creates a brief handoff only: no tool, retrieval or submission.
`/heaven fill` intentionally prefills; a human submits via normal host approval.
`/heaven dismiss` clears the notice. Only an explicitly requested band is drawn,
and its contents read current state rather than retaining a stale draft.
