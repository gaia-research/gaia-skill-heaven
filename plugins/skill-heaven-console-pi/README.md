# Pi Full console (preview)

Separate Pi package, identity `skill-heaven-console`. Install/remove with
`pi install "<staged-console-dir>" --approve` / `pi remove "<staged-console-dir>"`.
Core is unchanged. Local packages load staged files directly after reload.

Own status key, `/heaven [section]` widget, `/lens <need>` explicit preview on
Core's existing in-process client, `/heaven fill` editor prefill only, and
`/heaven dismiss`. No model tool, sendUserMessage, independent engine or shared writes.
Pi 1.0.4 API evidence informed this artifact; live Full compatibility is unclaimed.
See [adapter contract and remaining cells](../../packages/console/README.md).
