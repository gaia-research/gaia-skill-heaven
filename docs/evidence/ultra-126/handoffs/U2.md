## Implementation summary

- **Pure manifest builder & closed-record schema (`packages/core/src/campaign/manifest.ts`):**
  - Builds `skill-heaven/campaign-manifest/v1` from a cited U1 `CampaignReconRecord` and the agent's selection.
  - Each `CampaignManifestEntry` cites its retrieved card by `reconId`, `gapIndex`, `gap` query, and `cardRef` (`recon:<reconId>:gap:<gapIndex>:card:<id>`) and keeps all six lenses as separate fields (`retrieval`, `lane`, `installability`, `arbor`, `graph`, `freshness`).
  - No combined score, rank blend, or weight field exists anywhere in the schema (INV-U5, K6), enforced at compile time (`AssertExactKeys`) and runtime (closed-record descriptor checks + key allowlist snapshots).
  - Graph relations (`entry.graph.relations`) annotate entries and are never consulted to filter or reorder `manifest.entries` (K5).
  - Human-led entries (`lane === "human-led"` or `invocation === "human"`) are marked `convergenceOnly: true` on both `entry` and `entry.lane` (FD-3).
  - Both `buildCampaignManifest` / `tryBuildCampaignManifest` and `isValidManifestForRecon` / `parseCampaignManifest(manifest, recon)` reject any entry not present in the cited recon record (or missing from `recon.citations`), any selection from a `no-match` or `refused` gap, and any tampered lens value.
- **Deterministic text renderer & extensible group API (`packages/skill-summon/src/campaign/render.ts`):**
  - Renders `CampaignManifest` deterministically with zero I/O, clock, or randomness.
  - Absent lenses and sub-measurements render explicitly as `absent` (`"not measured"` / `"not published"`), never as `0`, `0.00`, `0 claims`, `0 relations`, `0 edges`, or `0d`.
  - Operational `refused` gaps render as `Retrieval refused (<reason>) — capability not measured / unknown (operational refusal, not a no-match and not a signal to explore)`, distinct from `no-match` (`No capability found`).
  - Graph relations disclose `pairApplicable=true (publication-time only; not runtime assurance)` or `pairApplicable=false (inapplicable at publication time; not runtime assurance)` and state that conditions and publication-time `pairApplicable` are not evaluated or assured at runtime.
  - Exports the pure group API (`createManifestRenderGroup`, `withManifestGroup`, `buildDeclaredNotMeasuredGroup`, `renderManifestGroup`, `options.groups`, `options.includeDeclaredNotMeasuredGroup`) so U8 can add the `"Declared, not measured"` group and U3 can extend the renderer with control-strategy groups.

## Security considerations, known limitations and outstanding issues

- **Security:** `parseCampaignManifest` and `validateReconRecord` use closed-record descriptor inspection (`Object.getOwnPropertyDescriptors`, `Reflect.ownKeys`, prototype checks, and dense `strictArray` checks), never invoking getters or accepting inherited/symbol/non-enumerable properties, and return deep-frozen snapshots via `immutableSnapshot`. Every externally supplied string rendered by `renderCampaignManifest` is escaped onto a single line via `displayField` / `escapeControlText` so hostile metadata cannot forge lines or inject authority phrases (`authorityHits === []`). The word `"ratify"` appears nowhere.
- **Known limitations:** U2 provides the pure `skill-heaven/campaign-manifest/v1` builder, schema parser, recon validator, and deterministic manifest renderer + group API; charter proposal (`propose`), control-strategy rendering, and operator decision channels belong to U3, and Arbor cache/pin refresh belongs to U8. Ultra copy remains `"provisioned"`.
- **Dependency changes:** None.
- **Outstanding issues:** None.
