## Why minimal edits to `render.ts` were needed beyond U2's group API

U2's `render.ts` already provided `DECLARED_NOT_MEASURED_GROUP_ID`, `buildDeclaredNotMeasuredGroup`, `withManifestGroup`, and verbatim `displayField` rendering for `conditions` and `authority` (`actor`, `basis`), and `judgeArborBand` already abstained with `no-governed-claim`. Only the gaps where U2 could not satisfy the five pending rules via the group API alone were patched minimally in `render.ts` (leaving `options.groups` / `createManifestRenderGroup` / `withManifestGroup` untouched for U3):
1. U2's `buildDeclaredNotMeasuredGroup` iterated all `entry.arbor.claims` without filtering to `support === "expert-declared" && interpretationSource === null`, and `renderArborLens` hardcoded `"declared, not measured"` even for governed claims.
2. U2's `renderCampaignManifestLines` omitted `"Declared, not measured"` unless callers explicitly passed `includeDeclaredNotMeasuredGroup: true`.
3. U2's `buildDeclaredNotMeasuredGroup` did not distinguish `human-led` claims as convergence-point candidates (proposed to the person; never auto-invoked) or state non-inference of band/permission on `model-led` claims.
4. U2's `renderGraphLens` did not annotate declared edges as `unverified hypothesis` selectively when `pairApplicable === true` and both endpoints are verified.
5. `collapseLineControls` / `escapeControlText` did not escape `U+2028`/`U+2029` (Terra Round 1 finding on `8ed4496`).
