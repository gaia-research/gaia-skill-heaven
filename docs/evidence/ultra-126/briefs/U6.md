## Deliver

- `packages/skill-summon/src/campaign/ops/incident.ts`: `campaign{op:"incident"}`
  takes a packet with these fields, all required: work affected, what was attempted,
  why progress stopped, branches explored, evidence, skills consulted, what is ruled
  out, at least two options with tradeoffs, the reason it needs a person (exactly one of
  `product-intent | irreversible | authority-boundary | charter-gap`), the questions,
  and what happens after the answer. The schema is closed: unknown keys are rejected.
- **Preparation check (INV-U8, K7):** refuse the packet unless the trace holds at least
  one preview or summon for an affected unit since it became unstable, or an explicit
  refusal record for it. Check the trace, never the packet's own claims.
- **Blocking (K8):** an open incident moves its affected units to `needs-human`. It
  blocks only units that depend on them. Independent units keep flowing through `next`.
- Human-led skills that would help are **named** in the packet for the person to
  invoke. They are never summoned on the automatic path (FD-3). U5's gate already
  refuses them; add a test, not a second rule.
- A deterministic packet renderer in `render.ts` style, with absent fields rendered
  as absent. It passes the authority regression.
- `operator.ts` `answer`: arrives on the operator channel only (elicitation, same
  FD-11 rules). It is written to the trace **verbatim**, with attribution, channel,
  multiplexed and optIn, and the affected units resume. Agent text cannot answer.
- `/skill-ultra answer` in `skill-ultra.md` and `render-ladder.mjs`; commit the
  rendered outputs. `npm run build:mcp`.

## Tests

A packet with no preparation in the trace is refused, and so is one with fewer than
two options or an unknown reason. An open incident blocks only dependent units: a
graph test with an independent branch that keeps completing. The answer is stored
byte-for-byte, including whitespace and non-ASCII. An answer in agent text, a
summoned body or a tool result is not an answer. Elicitation cancel or decline leaves
the incident open. A multiplexed env without opt-in fails closed. Replay of a trace
with an incident and an answer is byte-identical. Authority regression is green.
