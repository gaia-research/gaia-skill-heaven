## Fixture

`probes/p1/server.mjs` is a zero-dependency stdio MCP server (JSON-RPC 2.0, newline
delimited). It logs every inbound message, with an ISO timestamp, to
`$P1_LOG` (a JSONL file in the run dir). It exposes:

- `probe_elicit`: when called, sends `elicitation/create` to the client
  (message "P1 operator check: type the word ALPHA", `requestedSchema` with one
  string field `word`). It returns to the model only `{"sent": true}`, and logs the
  client's response or error.
- `operator_decide`: a no-op tool that logs its call. It tests channel 3
  (the permission prompt).

`probes/p1/write-record.mjs` writes `{ts, argv, pid}` to `$P1_LOG.cmd.json`.
`probes/p1/commands/probe-decide.md` is a slash-command fixture whose body
contains a pre-execution line `` !`node <abs path>/write-record.mjs decide-x` ``.
Use the `allowed-tools` frontmatter if the docs require it. Install it as a
project command in the run dir's `.claude/commands/`, which stays inside the
mktemp dir.
