## Deliver

- `packages/core/src/campaign/manifest.ts`: a pure builder from a recon record plus
  the agent's selection, producing `skill-heaven/campaign-manifest/v1`. Each entry
  points at a retrieved card in the cited recon record (by recon id + gap +
  card ref) and keeps every lens as a **separate field**: retrieval, lane,
  installability, Arbor claims, Graph relations, freshness. **No combined
  score, rank blend or weight field exists in the schema** (INV-U5, K6).
  Relations annotate; they never filter or reorder entries (K5). Human-led
  entries are marked convergence-only (FD-3).
- `packages/skill-summon/src/campaign/render.ts`: deterministic text renderer
  for the manifest block. Absent lenses render as absent ("not measured", "not
  published"), never as zero or as a guess. Keep the renderer pure so U3's
  control-strategy renderer and U8's declared-claims group can extend it. Export a
  small group API that U8 can add a "Declared, not measured" group to.

## Tests

The schema parser rejects any field combining lenses, as a closed-record test.
**Also add a test that fails if someone adds a combined-score field to the type**, for
example a key allowlist snapshot. An entry not present in the cited recon record is
rejected. Relations never change entry order: property test over shuffled relation
inputs. Absent lenses render as absent. The renderer output passes the authority
regression. Rendering is byte-stable for the same input.
