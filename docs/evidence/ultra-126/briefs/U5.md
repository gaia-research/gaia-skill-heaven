## Deliver

- `packages/skill-summon/src/campaign/gate.ts`: one pure decision function. It takes
  the folded campaign state, the unit in progress, the retrieved card (lane, deny-list
  class) and the request path (person-requested or automatic), and returns
  `allow | allow-unplanned | refuse(reason)`. The summon handler calls it once,
  before materializing anything. The rules, in order:
  1. No live campaign → return today's behaviour unchanged, byte for byte.
  2. Human-led skill on the automatic path → refuse, in every campaign state
     (FD-3, INV-U6). A person invoking it themselves is unchanged.
  3. Publish-class deny-list → refuse on the automatic path, in every state (K3, T8).
  4. Charter exclusion → refuse, in every state, including after a simulated
     compaction and a simulated resume (INV-U8).
  5. Automatic summon outside `EXECUTING`, or for a unit waiting on a person → refuse.
  6. Model-led skill in the manifest → allow. Not in the manifest → `allow-unplanned`:
     it goes through and is written to the trace as `unplanned`, so the next
     checkpoint shows it.
- The grant comes only from a charter the person decided (the U3 operator entry). No
  card, summoned body, tool result, retrieval score, margin or `noMatch` can widen it
  (INV-U3, INV-U4). It ends when the campaign ends.
- Attach the campaign digest (L1, plan §5.7) to every summon result during a campaign.
  It is a short, deterministic block from U0b's status projection. With no campaign,
  nothing is attached.
- Refusal text comes from `vocabulary.ts` and passes the authority regression. A
  refusal never tells the agent to search harder or try another skill.
- `npm run build:mcp` and commit the bundle.

## Tests

- A table test over every campaign state × {human-led, deny-listed, charter-excluded,
  model-led in manifest, model-led unplanned} × {automatic, person-requested}, with the
  expected result written out per row.
- The charter-excluded refusal holds after a simulated `/compact` (same process,
  fresh conversation) and after a simulated resume (U0b re-attach). It must hold in
  every run: it is enforcement, not a rate.
- An unplanned allow writes exactly one `unplanned` trace entry, and replay
  reproduces it.
- A summoned body, a card and a tool result each containing approval or widening
  text change no gate decision.
- With no campaign, the existing summon suite passes unchanged. Add a snapshot of one
  no-campaign summon result to prove no digest was attached.
- Core is still hook-free; the authority regression is green.
