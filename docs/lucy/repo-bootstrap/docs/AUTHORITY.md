# Lucy authority for the Rive build

## Current source authority

For the first Rive implementation, the source authority remains the current owner-approved v5 Lucy masters in Skill Heaven:

`packages/site/src/assets/lucy/v5/masters/`

The v5 production receipt records those source PNGs as owning:

- identity
- pose
- composition
- silhouette
- alpha

The Rive repo should record exact source repository commit + file hashes when the masters are imported.

## State policy

### Zero

Carry the approved master forward. Preserve the seated zen pose, closed eyes, normal gravity, one katana, no wings, no shards.

### Heaven

Carry the approved master forward. Preserve the falling/gravity language, both diamond eyes, one katana, and cyan-blue ordered glass-shard language.

### Hell

Carry the approved master forward. Preserve the inversion relationship, closed-eye treatment, continuous red tear, one katana, and fragmented shard language.

### Ultra

Treat the approved master as authority **unless the rig-suitability review proves it cannot produce acceptable motion**.

The current v5 delivery records known owner-accepted exceptions around opacity/fringe and its source geometry differs from the other states. Review:

- hair separability
- face/eye isolation
- dual-katana separation
- gold shard/wings separation
- transparent-edge quality
- room for deformation without destroying the silhouette

If those fail materially, produce a bounded new Ultra gold-master candidate with current Lucy image-production rules and explicit owner review.

A new Ultra source is not authoritative merely because it is easier to rig.

## Image-production rules

Prefer:

- deterministic separation
- masks
- crop-patch-composite edits
- bounded reconstruction of hidden pixels
- local compositing
- pixel-diff / silhouette review
- current Skill Heaven `lucy-image-production` rules

Whole-state regeneration is a last resort.

## Identity gates for Rive

Every candidate should be reviewable against the gold master with:

- full-body overlay
- face crop
- eye treatment
- hair silhouette
- ribbon silhouette
- weapon count/shape
- wing/shard state language
- key transition frames

The neutral/state hold frame should match the authority as closely as the chosen rig architecture permits.
