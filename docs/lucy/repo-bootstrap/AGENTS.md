# AGENTS.md

## Mission

Ship Lucy as a production Rive character for Gaia Skill Heaven.

The product outcome is the judge: Lucy must feel alive across Zero, Heaven, Hell, and Ultra while remaining unmistakably the approved character.

## Read first

1. `README.md`
2. `docs/AUTHORITY.md`
3. `docs/CHARACTER-CONTRACT.md`
4. `docs/SHIPPING-BRIEF.md`
5. the current Skill Heaven Lucy production authority and v5 source records

## Hard boundaries

- Use Rive. Do not build a replacement renderer, mesh engine, physics system, or general authoring Studio.
- Preserve owner-approved Lucy identity.
- Do not regenerate Zero, Heaven, or Hell because separation/rigging is inconvenient.
- Ultra may receive a new master only after a documented suitability failure and owner approval.
- Keep animation logic in Rive when practical; keep website integration semantic.
- Do not create `lucy-player` unless a second consumer or substantial independent runtime layer makes it clearly useful.
- Do not delete or rewrite Skill Heaven's historical Lucy production evidence.

## Working style

No phase ceremony.

Create a visual candidate viewer early. Compare against gold masters at full state, face, hair silhouette, and transition frames. Iterate on real motion before touching the production hero broadly.

Strong agents may orchestrate subagents, Rive CLI/RML, Rive MCP, computer use, image-production tools, worktrees, browser tests, and visual QA.

## Definition of finished

Do not declare success because `lucy.riv` builds. Declare success when Lucy reads correctly and feels alive in the actual Skill Heaven product.
