# Lucy — Full Website Commission Pack

This list treats Lucy as a **modular production asset system**, not a collection of unrelated finished illustrations. The artist should paint the expensive canonical character work once, then deliver separable hair, ribbon, wing, sword, shard, lighting, and state layers that can be recomposed across the site.

## H. Mandatory source delivery structure

For each major state render, request separable layers/groups:

- body / skin
- uniform
- rear hair
- front hair
- eyes
- ribbon
- left wing
- right wing
- individual FX/shards
- katana
- secondary katana (Ultra)
- tear
- lighting/glow
- contact/ground shadow

Deliver:

- layered PSD / CLIP / equivalent source
- 4K+ master exports
- transparent PNG
- WebP web exports
- no baked text
- generous crop-safe area
- consistent Lucy proportions and face

## Commission strategy

Treat **A–C as the core character commission**, **D as the reusable FX kit**, and **E–G mostly as derivative layout/export work**. This prevents paying for dozens of independent illustrations that could have been assembled from the same canonical masters.
