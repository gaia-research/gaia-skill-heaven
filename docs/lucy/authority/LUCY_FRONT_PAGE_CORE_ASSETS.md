# Lucy — Hero + Full Front Page Core Asset List

This is the smallest complete asset pack needed to build a premium Skill Heaven homepage around Lucy without commissioning the entire long-term asset universe.

## Priority P0 — absolutely required

### 1. Canonical Lucy Master Sheet
Purpose: single source of truth for all website work.

Must include:
- Zero / Heaven / Hell / Ultra
- neutral turnaround
- eyes
- hair/ribbon behavior
- wings
- katana
- barefoot reference
- palette/materials

### 2. Primary Homepage Hero Render
- premium full Lucy illustration
- Heaven or Ultra
- transparent master
- generous negative space
- full saturation and canonical skin/hair rendering
- hair and ribbon motion fully resolved
- wings and weapon visible

### 3. Alternate Homepage Hero Render
- state opposite the primary choice, usually Heaven ↔ Ultra
- enables campaign/seasonal/A-B variation without redesigning page structure

### 4–7. Four Canonical Full-State Illustrations
- **Zero:** seated zen, closed eyes, hair down, one katana, no wings
- **Heaven:** falling, both diamond eyes open, blue prism wings, one katana
- **Hell:** distinct falling pose, closed eyes + red tear, full inversion, white background, one katana
- **Ultra:** distinct falling pose, one diamond eye + one closed tear eye, gold highlights, dual katanas

### 8. Responsive Hero Pair
- desktop wide hero composition
- mobile portrait hero composition

The mobile piece must be re-authored rather than merely cropped.
