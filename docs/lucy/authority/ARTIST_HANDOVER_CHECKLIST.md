# Lucy Artist Handover Checklist

Use this as the approval checklist for a commission or internal art pass.

## Character invariants
- [ ] Same face/anatomy in all four states
- [ ] Shoulder-length silver-white hair
- [ ] Original sailor uniform silhouette preserved
- [ ] Prismatic sailor ribbon preserved
- [ ] Barefoot in every state
- [ ] Traditional steel katana, not glass/energy blade
- [ ] No armor, horns, crown, boots, or biological wings

## Original-reference rendering
- [ ] Skin retains saturated pink/cyan reflected light
- [ ] Porcelain skin has strong modeled shadows, not flat cel fill
- [ ] Hair uses high-saturation white/cyan/blue lighting
- [ ] Pink/violet prism accents remain controlled rather than muddy
- [ ] Hair flow is high quality and physically legible
- [ ] Ribbon airflow agrees with hair motion

## Zero
- [ ] Seated zen pose on ground
- [ ] Closed neutral eyes
- [ ] Hair falls downward normally
- [ ] One katana resting nearby/horizontally
- [ ] No wings whatsoever
- [ ] Deep-black background option

## Heaven
- [ ] Unique falling pose
- [ ] Both diamond eyes open
- [ ] Body falls while hair/ribbon flow upward
- [ ] One katana
- [ ] Ordered blue/cyan shard wings
- [ ] Saturated prismatic lighting

## Hell
- [ ] Unique falling pose, not recolored Heaven pose
- [ ] Eyes closed
- [ ] Single red tear
- [ ] Whole scene is chromatically inverted
- [ ] Skin/uniform/hair/ribbon/weapon reflections participate in inversion
- [ ] White background
- [ ] Highly fragmented inverted shard wings
- [ ] One katana

## Ultra
- [ ] Unique decisive falling pose
- [ ] One diamond eye open
- [ ] Opposite eye closed with red tear
- [ ] No inversion anywhere
- [ ] Exclusive gold interference in hair/ribbon/wings/lighting
- [ ] Two matching steel katanas
- [ ] Body falls while hair/ribbon flow upward

## Production delivery
- [ ] Layered editable master
- [ ] Body/skin separated
- [ ] Uniform separated
- [ ] Front/rear hair separated where possible
- [ ] Eyes separated
- [ ] Ribbon separated
- [ ] Left/right wings separated
- [ ] Individual FX shards separated
- [ ] Katana separated
- [ ] Second Ultra katana separated
- [ ] Tear separated
- [ ] Lighting/glow separated
- [ ] Transparent 4K+ exports
- [ ] No baked text
- [ ] Generous crop-safe margins
